# Joystick Pack (third-party assets)

Sample **Basic Setup** menggunakan prefab dan sprite dari **[Joystick Pack](https://assetstore.unity.com/packages/tools/input-management/joystick-pack-107631)** di Unity Asset Store.

This sample includes **Joystick Pack** prefabs and sprites from the [Unity Asset Store](https://assetstore.unity.com/packages/tools/input-management/joystick-pack-107631).

## Catatan / Notes

- Prefab dan sprite di folder ini hanya untuk demo sample **Basic Setup**.
- Script runtime Joystick (mis. `Joystick`, `FixedJoystick`) tetap disertakan di package core (`Dependency/Joystick Pack/Scripts`) agar komponen `JoystickInputActionRaiser` dapat digunakan.
- Untuk lisensi lengkap, ikuti ketentuan Asset Store pada asset asli di atas.
