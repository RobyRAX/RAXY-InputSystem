# Joystick Pack (third-party assets)

The **Basic Setup** sample includes prefabs and sprites from **[Joystick Pack](https://assetstore.unity.com/packages/tools/input-management/joystick-pack-107631)** on the Unity Asset Store.

## Notes

- Prefabs and sprites in this folder are provided only for the **Basic Setup** demo.
- Joystick runtime scripts (e.g. `Joystick`, `FixedJoystick`) remain in the core package (`Dependency/Joystick Pack/Scripts`) so `JoystickInputActionRaiser` can be used without re-importing vendor code.
- For full licensing terms, follow the Asset Store listing for the original asset linked above.
